# Backend Internals (bei)

The purpose is to teach how backend internally works.
For that want to build an application, which uses SQLite, and uses as minimal backend python as needed. The application takes (creator_name, song_desc, song_file_name). It can take them from command line using curl, or from a page showing in the root with /upload route. The html file, when you fill the details and upload an mp3 file from your machine. It show what is request sent with POST method and what is the response bellow the actual UI. The details are like expandable JSON details. Along with that the backend also writes to the terminal, like received POST requestion on so and so route, calling this method. That method say's I need to save these details in database, so I am writing this SQL query like this and saving in the database. And also prints the response of the DB call. And then logs what is being returned back as part of the respose to the API and how th edetails are packed in the response. The default route / shows the list of songs already present as grid cards and has options to play the songs. When the play button is clicked, it shows how the request is sent back and how the response it gets. Similarly when the route / is hit the back end also shows what api is being hit and what it is doing what query it is writing and what it got from the Database and how it is packing those details and sending back in the reponse. The front end also shows bellow what is the request sent and what is the response it got. It's like at the end of each page in the front end this is shown always.So this app avoids authentication, pagination, becuase it is tested by a person on his own in his computer by running the server on his Ubuntu VM in WSL. Keep very less dependencies on libraries but bring just those libraries which make the code even simpler for the backend to do. No middleware, just backend APIs calling DB calls and packing the response back. There are only two routes / and /upload, these are the html pages that are sent back by the server. in the page where all are listed and upload button is provided to start uploading new songs.

The code must be inside be/ folder
